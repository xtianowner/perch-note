# Perch — 产品设计文档 v0.1

**创建时间**: 2026-05-15 11:46:39
**更新时间**: 2026-05-15 11:50:00

## 1. 一句话定位

> 永远置顶的桌面浮窗记录簿，输入即留时间戳，每条都能一键复制纯文本。

## 2. 用户场景

用户在做主任务（与 Claude 对话 / 看 Chrome / 写代码），需要随时记一笔：
- 一个临时想法
- 一个 URL / 一段命令 / 一个 ID
- 当前任务的进度坐标
- 与外部沟通时摘录的一句话

**关键摩擦点**：传统笔记 app 切窗口就丢焦点；便利贴 app 多数样式重、没时间戳、没法搜。Perch 的核心是**永不消失 + 时间戳 + 易复制**三件套。

## 3. 核心产品决策（已与用户确认）

| 决策 | 选择 | 理由 |
|---|---|---|
| 数据形态 | **混合：默认 timeline 追加 + 任意条可编辑** | 兼顾"流水账无负担"和"事后修正" |
| 内容格式 | **纯文本 (plain text)** | 避免用户输入 markdown 符号时被渲染破坏；复制粘贴到其他工具不带格式污染 |
| 复制行为 | **每条独立 copy 按钮**，复制原始纯文本 | 用户高频场景是把记录贴到对话/邮件/代码注释，不能带 `*` `#` `` ` `` 等字符干扰 |
| 时间戳 | 自动生成创建时刻；显示用相对时间（"3 min ago"），hover 显示绝对时间 | 浏览时轻量；导出时用绝对时间 |
| 存储位置 | 本地 SQLite | 离线优先；后期再考虑可选 sync |
| 平台 | macOS + Windows | 跨设备一致 |

## 5. 数据模型

```sql
CREATE TABLE entries (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    content     TEXT NOT NULL,        -- 纯文本，原样存储
    created_at  INTEGER NOT NULL,     -- Unix ms
    updated_at  INTEGER NOT NULL,     -- Unix ms (=created_at if never edited)
    pinned      INTEGER DEFAULT 0,    -- 0/1
    deleted_at  INTEGER               -- 软删除时间，NULL=未删
);

CREATE INDEX idx_entries_created ON entries(created_at DESC);
CREATE INDEX idx_entries_active ON entries(deleted_at) WHERE deleted_at IS NULL;
```

**约定**：`content` 字段是 raw text，渲染时一律用 `<pre>` 或 `white-space: pre-wrap` 的 `<div>`，**不经过任何 markdown / HTML 解析**。

## 6. UI 形态（V1 草图）

```
┌──────────────────────────────────┐
│ ≡  Perch              ─ □ ✕     │  ← 顶部 toolbar (拖动 / 折叠 / 关闭)
├──────────────────────────────────┤
│ 3 min ago                  [📋] │  ← 每条右侧 copy 按钮
│ 找 demo 视频用的关键词:           │
│ "japanese commute documentary"   │
├──────────────────────────────────┤
│ 12 min ago                 [📋] │
│ https://example.com/foo/bar      │
├──────────────────────────────────┤
│ 1 h ago                    [📋] │
│ TODO: 给 ETL 加 retry            │
├──────────────────────────────────┤
│ ┌──────────────────────────────┐ │
│ │ Type and press Enter...      │ │  ← 输入框永远聚焦
│ └──────────────────────────────┘ │
└──────────────────────────────────┘
```

**交互细节**：
- 进入 app → 输入框自动获焦
- `Enter` 提交，`Shift+Enter` 换行
- 列表新条目从底部冒出（最新在底，类似 chat），或从顶部插入（最新在顶，类似 timeline）—— V1 实现"最新在顶"
- 鼠标 hover 某条 → 显示 [copy] / [edit] / [pin] / [delete]
- copy 点击 → `navigator.clipboard.writeText(entry.content)`，按钮短暂变 ✓ 反馈
- 编辑模式：双击条目，inline 改为 textarea，`Esc` 取消，`Cmd/Ctrl+Enter` 保存
- 拖拽窗口边缘可调大小；最小尺寸 280×200

## 7. 跨平台「永远置顶」实现

| 平台 | 实现 | 已知边界 |
|---|---|---|
| macOS | `window.setAlwaysOnTop(true)` + `NSWindow.level = .floating` | 默认 floating level 在 fullscreen app 之上仍可见；进入 "Mission Control" 时短暂被遮 |
| Windows | `SetWindowPos(HWND_TOPMOST)` | 全屏游戏 / 全屏视频可能强制覆盖 — 可接受 |

Tauri 的 `alwaysOnTop` 配置 + `set_always_on_top` API 已封装上述差异，V1 不需要手写 native 代码。

## 9. 非目标（明确排除）

- ❌ 富文本编辑 / markdown 渲染 — **核心原则：纯文本进、纯文本出**
- ❌ 协作 / 多人共享 — 这是单人工具
- ❌ AI 总结 / 智能分类 — V3 后再议
- ❌ 移动端 — Tauri Mobile 还在 beta，暂不考虑
