# Perch 功能文档

**创建时间**: 2026-06-15 14:14:53
**更新时间**: 2026-06-15 14:14:53

> 一句话：永远置顶的桌面浮窗记事本，纯文本进、纯文本出。本文按功能逐项说明行为与边界。
> 安装 / 运行见 [README.md](../README.md)；UI 设计决策见 [ui.md](./ui.md)；代码模块见 [modules.md](./modules.md)。

---

## 1. 永远置顶浮窗
- 默认 360 × 480 窗口，`alwaysOnTop = true`：切到任何应用都不被遮挡。
- 最小可用尺寸 280 × 200，所有元素在小窗下仍可读可点。
- 顶部留白区可拖动窗口（`-webkit-app-region: drag`）。

## 2. 记录与编辑
- 底部输入框打字，`Enter` 新建一条（`Shift+Enter` 换行；中文输入法 composing 期间 `Enter` 不误提交）。
- 每条记录是一个**始终可编辑的 textarea**——没有"编辑 / 查看"两态切换，点开即改。
- **自动保存三道防线**：
  1. 停手 **15 秒** 自动保存（每次按键重置计时）；
  2. 焦点离开（blur）立即保存；
  3. 组件卸载（关窗 / 列表重排 / 过滤）兜底保存。
- 写入门控：内容与上次相同则不发数据库请求。
- **每条可选标题**（标题行单独一栏）。

## 3. 修改时间显示
- 每条头部并排显示 **绝对修改时间 · 相对时间**，例：`2026-06-15 10:49 · 5 分钟前`。
- 绝对时间格式跟随 Settings 的"时间戳格式"：
  - `本地` → `YYYY-MM-DD HH:MM`（去秒，保持紧凑）；
  - `ISO` → `YYYY-MM-DDTHH:MMZ`（UTC）。
- hover 头部时间，tooltip 给出完整的 **修改于 / 创建于** 时间。
- 标记：被编辑过（修改时间 > 创建时间）显示 `(已编辑)`；保存成功瞬间闪现 `✓ 已保存`。

## 4. 模糊搜索 + 命中高亮定位
- **唤起**：`⌘F` 或点顶栏 🔍；`Esc` 或 ✕ 收起并清空。
- **匹配**：查询按空格拆词，每个词都须是 标题+内容 的**子串**（大小写不敏感），多词之间是 AND。例：
  - `密码` → 仅含"密码"的条目；
  - `服务器 密码` → 同时含两者的条目。
- 顶栏搜索框右侧实时显示**匹配条数**。
- **卡内高亮定位**：搜索激活时，命中条目的内容切换成**带高亮的只读视图**——命中词标黄，并**自动滚动到第一处命中**，长笔记也能一眼定位。
- **点击内容**即切回可编辑文本框（光标进入），编辑完点别处自动保存并回到高亮视图；清空搜索恢复正常。
- **搜索时禁用拖拽**：避免在过滤后的子集上拖动写错排序。
- 备注：标题命中暂不高亮（标题短、本就可见）。

## 5. 字体连续缩放
- `⌘ +` 放大 / `⌘ −` 缩小 / `⌘ 0` 复位 100%。
- 范围 **70% – 180%**，步进 10%，**记忆到本地**，重启保持。
- Settings 面板内也有 `−  当前%  +  ⟲` 步进器，即时生效。
- 解决痛点：macOS 下系统级 `⌘+` 无法缩放 Tauri 窗口内容。
- 极小辅助文字（计数徽标 / 分区标签）刻意不参与缩放，保持层级感。

## 6. 置顶
- 每条右上 📌 一键置顶 / 取消；置顶条目始终浮在列表顶部，卡片带 accent 左边条标记。
- 列表分「置顶 / 其他」两区，各自独立。

## 7. 拖动排序
- 抓住每条左上角的拖动手柄上下拖动调整顺序。
- 置顶区与普通区**各自独立排序**，跨区拖动天然不可能（与"置顶浮顶"语义一致）。
- 顺序持久化到数据库（`sort_order`），重开保持。

## 8. 删除（软删除）
- 🗑 两步确认：首次点变红显示"再点确认"（4 秒倒计时，超时自动还原）。
- **软删除**：仅打 `deleted_at` 标记，不物理删除——数据仍在库里，可经数据库恢复。

## 9. 复制（纯文本）
- 每条 ⧉ 一键复制：`标题 + 时间戳 + 内容`，**全程不渲染 markdown**，所打即所粘。
- 复制读取**屏幕上的 live draft**——还没自动保存的改动也照样粘出。
- **自定义前缀 / 后缀**：在 Settings 里附加签名 / 标签 / 引用前缀，可选放在内容之前或之后。
- 时间戳格式（本地 / ISO）在 Settings 切换，并有实时预览。

## 10. 设置项（Settings，⚙）
| 项 | 说明 |
|---|---|
| 语言 | 中文 / English（即时切换 + 预览） |
| 字体大小 | `−  %  +  ⟲` 步进器（即时生效；亦可用 `⌘ +/−/0`） |
| 时间戳格式 | 本地 / ISO 8601（影响头部时间 + 复制输出） |
| 自定义文本 | 复制时追加的前缀/后缀文本 |
| 自定义文本位置 | 内容之前 / 之后 |
| 剪贴板预览 | 实时预览复制出来的样子 |

设置持久化在浏览器 `localStorage`（key `perch.settings.v1`）。

## 11. 主题与外观
- **浅色 / 深色**跟随系统 `prefers-color-scheme`，两套都打磨过（深色非纯黑）。
- 单 accent 克制配色，Swiss minimal 风格；尊重 `prefers-reduced-motion`。

## 快捷键

| 快捷键 | 作用 |
|---|---|
| `⌘ F` | 唤起 / 聚焦搜索框 |
| `Esc` | 收起搜索 |
| `⌘ +` / `⌘ −` | 放大 / 缩小字体 |
| `⌘ 0` | 字体复位 100% |
| `Enter` | 底部输入框提交新建（`Shift+Enter` 换行） |

> Windows / Linux 上把 `⌘` 换成 `Ctrl`。

## 数据与存储
- 笔记数据：本地 SQLite。
  - macOS：`~/Library/Application Support/com.tian.perch/perch.db`
  - Windows：`%APPDATA%\com.tian.perch\perch.db`
- 标准 SQLite 文件，可 `sqlite3` 直接打开 / 备份 / 跨机复制。
- 设置：webview `localStorage`。
- 无账号 / 无云同步 / 无遥测。

## 已知边界 / 限制
- 搜索高亮目前覆盖**内容**，标题命中不单独高亮（标题短，本身可见）。
- 删除是软删除，UI 不提供"回收站"恢复入口（需要时可从 `perch.db` 手动恢复）。
- 暂无预编译二进制，从源码 `pnpm tauri build` 自行打包。
